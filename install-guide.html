유콜 (YOUcall)

사본 만들기부터 전자칠판 앱까지

교무실에서 학생을 호출하면 교실 화면에 크게 표시해주는 유콜(YOUcall)을, 아무것도 몰라도 처음부터 끝까지 따라 할 수 있게 정리했어요. 사본 만들기 → 배포 → (선택) 웹·PC·전자칠판 중 우리 교실에 맞는 방법으로 설치까지 이 한 페이지로 끝나요.

1

유콜이 뭐예요?

교무실 호출 + 전자칠판 홈스크린, 하나로

유콜은 교사가 교무실 PC에서 학생을 호출하고, 호출이 없을 때 교실 화면(태블릿·전자칠판·TV)은 시간표·급식·학사일정을 보여주는 이중 목적 웹앱이에요. 선생님을 선택하고 → 학년·반을 고르고 → 학생 이름을 누르면, 교실 화면에 크게 호출 알림이 뜨고 음성 안내(TTS)까지 자동으로 나와요.

📣

호출 + 메시지

"시험지 가지고 오세요" 같은 메시지와 어느 교무실로 오라는 위치까지 함께 표시돼요.

🗓️

교실 홈스크린

호출이 없을 때는 오늘 시간표·급식·학사일정·학급 메모를 보여주는 대기화면으로 동작해요.

💡
학교마다 자기 사본을 하나씩 가져가서 씁니다

제 시트를 그대로 쓰는 게 아니라, 아래 02 단계로 학교별 사본을 만들고 그 사본을 각자 배포해서 씁니다. 학생 명단이 서로 섞이지 않아요.

2

사본 만들기

우리 학교만의 유콜을 만드는 첫 단계

아래 버튼을 누르면 구글 시트가 자동으로 내 드라이브에 복사돼요. 원본에는 영향이 없으니 편하게 누르셔도 돼요.

📄 유콜 사본 만들기 구글 계정으로 로그인돼 있어야 해요 · 내 드라이브에 즉시 복사

버튼 클릭

구글 로그인이 안 돼 있으면 로그인 화면이 먼저 뜰 수 있어요. 로그인 후 자동으로 사본 만들기가 진행돼요.

사본 이름 바꾸기

제목을 알아보기 쉽게 바꿔주세요. 예) 유콜 - 00중학교

ℹ️
사본 안에는 이미 다 준비돼 있어요

학생목록·교사목록·설정·호출로그·학사일정 시트와 Code.gs·index.html 코드까지 전부 사본 안에 그대로 들어와요. 새로 만들 건 없고, 값만 채우면 돼요.

3

시트 채우기

학생 명단·교사 명단·학교 설정, 3가지만 넣으면 돼요

방금 만든 사본에서 아래 탭(시트)들을 순서대로 채워주세요.

🧑‍🎓학생목록 시트

열내용
A · 학년예: 1, 2, 3
B · 반예: 1, 2, 3
C · 번호예: 1, 2, 3 …
D · 이름예: 홍길동
E · 표시여부Y = 화면에 표시 / N = 숨김 (전학생 등에 활용)

🧑‍🏫교사목록 시트

열내용
A · 이름예: 김주현
B · 근무위치예: 2학년 교무실 — 학생 화면 호출 알림에 "📍 어디로 오세요"로 그대로 표시돼요

⚙️설정 시트

이 시트만은 표 형태가 아니라, 항목 이름 옆 칸에 값을 채우는 방식이에요. 가장 먼저 챙길 건 딱 하나예요.

🔐
학교명은 꼭 정확하게

"학교명" 칸에 정식 명칭으로 입력하세요 (예: "OO중학교"). 다음 단계(05)의 학교코드 조회가 이 이름으로 검색돼요.

그 외 테마(1~5)·자동닫힘시간·시정(1교시 시작시각 등)·긴급공지·학급메모는 나중에 언제든 바꿀 수 있어요. 지금은 기본값 그대로 두고 넘어가도 괜찮아요.

💡
NEIS API 키는 발급받지 않아도 돼요

급식·시간표 자동연동에 필요한 인증키가 이 사본에 이미 내장돼 있어요. 학교명만 정확히 입력하면 다음 단계에서 바로 연동돼요.

4

배포하기

딱 한 번만 하면 되는 설정 — 조금 길지만 그대로만 따라 하시면 돼요

Apps Script 열기

사본 스프레드시트 상단 메뉴에서 확장 프로그램 ▸ Apps Script를 클릭합니다.

배포 시작

새 창이 열리면 오른쪽 위 배포 버튼 ▸ 새 배포를 클릭합니다.

유형 선택

톱니바퀴(⚙) 아이콘을 눌러 "웹 앱"을 선택합니다.

설명 입력

알아보기 쉬운 이름을 적어요. 예) 유콜 v4.0

실행 사용자 · 액세스 권한 설정 (가장 중요)

"다음 사용자 인증으로 실행"은 반드시 나(Me), "액세스 권한"은 반드시 모든 사용자(Anyone)로 선택합니다.

배포 클릭

배포 버튼을 누르면 권한 승인 화면이 뜹니다. 05의 보안 경고 처리로 이어집니다.

URL 복사

승인이 끝나면 웹앱 URL이 생성됩니다. 이 주소를 꼭 복사해서 어딘가에 저장해두세요.

⚠️
실행 사용자·액세스 권한은 틀리면 안 돼요

"나"가 아닌 다른 값을 고르거나 "모든 사용자"가 아니면, 학생 화면이 열리지 않거나 매번 로그인을 요구할 수 있어요.

🔓보안 경고가 뜨면

배포 버튼을 누르면 "이 앱은 확인되지 않았습니다" 라는 경고가 뜰 수 있어요. 당황하지 않으셔도 돼요 — 본인이 직접 만든 앱이라 안전합니다. 구글이 개인이 만든 모든 스크립트를 일일이 검증할 수 없어서 뜨는 안내일 뿐이에요.

액세스 승인 클릭

구글 계정 선택

본인 계정을 선택합니다.

고급 클릭

화면 왼쪽 아래 "고급"을 누릅니다.

안전하지 않은 페이지로 이동

이어서 나오는 링크를 클릭합니다.

허용

"허용" 버튼을 누르면 웹앱 URL이 만들어집니다.

💡
나중에 시트나 코드를 수정했다면

배포 ▸ 배포 관리 ▸ 연필 아이콘 ▸ "새 버전" 선택 ▸ 배포를 누르면 돼요. 주소는 그대로 유지되고, 저장만으로는 반영되지 않으니 이 재배포 과정이 꼭 필요해요.

5

주소 확인 · 학교코드 연결

URL 두 종류 구분하기 + 급식·시간표 자동연동 마무리

방금 복사한 주소 하나로 교사 화면과 학생(교실) 화면이 나뉘어요. 뒤에 파라미터를 붙이는지 아닌지로 구분돼요.

용도주소 형태
📱 학생용 (교실)복사한 주소 그대로
https://script.google.com/macros/s/AKfyc...../exec
🖥️ 교사용 (교무실)뒤에 ?role=teacher 추가
https://script.google.com/macros/s/AKfyc...../exec?role=teacher
⚠️
?role=teacher 없이 접속하면

교사 PC에서도 학생용 화면이 열려요. 교무실 PC 북마크에는 꼭 ?role=teacher가 포함된 주소를 저장하세요.

💡
주소를 다시 확인하고 싶다면

Apps Script ▸ 배포 ▸ 배포 관리에서 활성 배포의 URL을 언제든 다시 볼 수 있어요.

🍚학교코드 연결하기 (급식·시간표 자동연동)

스프레드시트 새로고침

상단 메뉴에 새로 생긴 [유콜] 메뉴가 보일 거예요.

학교코드 조회 실행

유콜 ▸ 학교코드 조회(NEIS)를 클릭합니다.

학교 선택

동명 학교가 여러 개면 지역까지 보여주는 목록에서 번호를 선택합니다.

완료

설정 시트에 교육청코드·학교코드가 자동으로 채워지고, 이때부터 급식·시간표가 매일 자동 갱신돼요.

💡
주소가 너무 길다면

유콜 ▸ 짧은 주소 만들기를 실행하면 학생용 주소를 짧은 링크로 바꿔줘요. 전자칠판 앱 설정 화면에 입력할 때 훨씬 편해요.

6

어떻게 쓰실 건가요?

여기서부터 갈라져요 — 셋 중 하나를 고르시면 돼요

배포는 끝났어요! 이제 교실 화면(전자칠판)에서 이 주소를 여는 방법을 고르면 됩니다.

🌐 설치 없음

그냥 브라우저로 접속

설치 과정 없이 지금 바로 쓸 수 있어요. 모든 기기에서 동작해요.

＋ 07. 자세히 보기
🖥️ Windows PC

PC에 설치 (유콜 데스크)

전자칠판에 윈도우 PC가 연결돼 있다면 이걸 쓰세요. 브라우저 안 켜놔도 계속 대기해요.

＋ 08. 설치하기로 가기
📱 안드로이드 칠판

전자칠판에 설치 (유콜 보드)

전자칠판 자체가 안드로이드라면(앱 아이콘 화면) 이걸 쓰세요.

＋ 09. 설치하기로 가기
ℹ️
헷갈리면

전원을 켰을 때 화면 아래에 윈도우 시작 버튼(⊞)이 보이면 PC 설치, 안 보이고 앱 아이콘만 있으면 전자칠판 자체 설치예요. 둘 다 확실하지 않으면 그냥 웹으로 시작하세요 — 나중에 언제든 설치로 바꿀 수 있어요.

7

웹으로 바로 쓰기

설치 없이, 제일 간단한 방법

전자칠판이나 태블릿, 교실 TV의 브라우저만 있으면 돼요.

교실 화면 기기에서 브라우저 열기

전자칠판·태블릿·교실 PC의 Chrome(또는 기본 브라우저)을 엽니다.

학생용 주소 접속

05에서 확인한 학생용 주소(파라미터 없는 기본 URL)를 입력합니다.

우리 반 선택

시작 화면에서 학년·반을 선택하고 📣 시작하기를 눌러요. 이 클릭이 소리·음성을 활성화시켜요.

화면 그대로 두기

이 상태로 화면을 켜두면, 평소엔 시간표·급식이 보이는 대기화면, 호출이 오면 알림 화면으로 자동 전환돼요.

💡
매번 다시 여는 게 번거롭다면

이 주소를 브라우저 즐겨찾기(북마크)로 저장하거나, 안드로이드 Chrome이라면 우측 상단 메뉴 ▸ "홈 화면에 추가"를 하면 앱처럼 아이콘 하나로 바로 열 수 있어요.

⚠️
브라우저 탭을 닫으면 호출을 못 받아요

이 방식은 화면을 계속 켜두고 탭을 유지해야 호출을 받을 수 있어요. 자주 다른 용도로도 쓰신다면 08. PC용 설치나 09. 전자칠판 설치가 더 편해요.

이후 사용법(평소 화면 보는 법, 호출을 받으면 어떻게 되는지, 소리 설정)은 11. 사용법과 완전히 동일해요.

8

PC용 설치하기 — 유콜 데스크 (EXE)

윈도우 PC 연결형 전자칠판 전용 · 아래 버튼으로 바로 받아져요

ℹ️
우리 교실이 맞는지 확인

전자칠판에 윈도우 PC가 연결돼 있고, 전원을 켰을 때 바탕화면(시작 버튼 ⊞)이 뜨면 이 방법이 맞아요. 전자칠판 자체가 안드로이드라면 09의 APK를 쓰세요.

⬇️ YouCallDesk-Setup-1.0.0.exe 내려받기 v1.0.0 · 약 78MB · 항상 최신 버전으로 연결돼요
주소로 직접 입력할 때
github.com/kimju1416/youcall-desktop/releases/latest

다운로드

전자칠판에 연결된 PC(또는 교무실 PC에서 받아 옮겨도 됨)에서 위 버튼을 눌러 받습니다.

실행

다운로드된 파일을 실행합니다. 별도 확인창 없이 바로 설치가 진행돼요.

보안 경고 처리

윈도우 보안 경고(SmartScreen)가 뜨면 추가 정보 ▸ 실행을 누릅니다.

자동 실행

설치가 끝나면 유콜 데스크가 자동으로 실행되며 최초 설정 화면이 뜹니다.

⚠️
이 경고, 고장 아니에요

SmartScreen 경고는 스토어를 거치지 않은 배포용 프로그램이면 무조건 떠요. 직접 만든 프로그램이라 안전합니다 — 정상적인 과정이에요.

💡
교사 PC(호출하는 쪽)는 그대로 웹을 씁니다

유콜 데스크는 교실 화면 전용이에요. 교무실 PC는 지금처럼 웹(주소 뒤 ?role=teacher)을 그대로 쓰시면 돼요.

9

전자칠판 설치하기 — 유콜 보드 (APK)

안드로이드 전자칠판 전용 · 아래 버튼으로 바로 받아져요

ℹ️
우리 교실이 맞는지 확인

전원을 켰을 때 앱 아이콘 화면(Chrome, File Manager 등)이 뜨면 이 앱이 맞아요. 윈도우 바탕화면(시작 버튼 ⊞)이 뜬다면 08의 PC용 설치를 쓰세요.

다운로드

전자칠판에서 Chrome을 열고(홈 화면에 없으면 More Apps 안에 있어요) 위 버튼을 누르거나 주소를 입력합니다.

알림 누르기

다운로드가 끝나면 알림을 누릅니다. 또는 File Manager ▸ Download 폴더에서 파일을 눌러요.

「출처를 알 수 없는 앱」 경고가 뜨면 [설정] ▸ 「이 출처 허용」을 켜고 뒤로 갑니다.

설치 → 열기

[설치] ▸ [열기]를 누르면 끝이에요.

⚠️
이 경고, 고장 아니에요

🖥️유콜 데스크(EXE) 최초 설정

설정 화면 확인

설치가 끝나면 자동 실행되며 최초 설정 화면이 뜹니다.

웹앱 주소 입력

05에서 확인한 학생용 주소를 붙여넣습니다.

학년 / 반 입력

이 교실의 학년과 반을 입력합니다. (예: 3 / 2)

저장

저장하면 바로 대기화면(시간표·급식·학사일정)이 표시돼요.

📱유콜 보드(APK) 최초 설정

웹앱 주소 붙여넣기

05에서 확인한 학생용 주소를 입력칸에 길게 눌러 붙여넣기 합니다.

학년 / 반 입력

이 교실의 학년과 반을 입력합니다. (예: 3 / 2)

동작 방식 선택

아래 표를 보고 상시 화면형 / 상주형 중 하나를 고릅니다. 나중에 언제든 바꿀 수 있어요.

저장하고 시작하기

버튼을 누르면 바로 대기화면이 표시돼요.

⚠️
「연결 실패」가 뜨면

주소가 잘못 입력된 거예요. 05로 돌아가 주소를 다시 확인해 주세요.

🔀동작 방식 두 가지 — PC·전자칠판 둘 다 지원

상시 화면형 (기본·추천)상주형 (트레이)
평소 화면시간표·급식·학사일정·공지를 항상 표시숨어 있음 (전자칠판을 다른 용도로 사용)
호출이 오면알림 화면으로 전환앱이 자동으로 화면 앞에 등장
호출이 끝나면대기화면으로 복귀다시 숨음
이럴 때전자칠판을 유콜 전용으로 쓸 때수업자료·인터넷도 함께 쓸 때
ℹ️
바꾸는 방법이 서로 조금 달라요

APK는 ⚙️ 설정 화면에서 두 모드 중 하나를 바로 고릅니다. EXE는 트레이 아이콘 우클릭 메뉴의 체크박스 두 개(상시화면 표시 · 새 호출 시 창 자동 복원) 조합으로 같은 효과를 냅니다 — 둘 다 켜면 상시 화면형, "상시화면 표시"만 끄고 "자동 복원"을 켜면 상주형과 동일하게 동작해요.

⚠️
상주형은 대기화면이 안 보여요

평소 화면이 꺼져 있으므로 긴급공지·학급메모·시간표가 보이지 않아요. 공지를 학생들에게 계속 보여주려면 상시 화면형을 쓰세요.

🔐
APK 상주형을 고르셨다면

첫 실행 시 안내되는 「다른 앱 위에 표시」 권한을 허용해야 해요. 이 권한이 없으면 앱이 스스로 화면에 못 나오고 상단 알림만 표시돼요. (EXE는 이런 권한 설정이 필요 없어요 — 일반 윈도우 프로그램이라 바로 동작해요.)

＋

문제 해결 · 삭제

자주 묻는 질문과 앱 삭제 방법

  • 호출이 2~3초 뒤에 떠요 — 정상이에요. 구글 서버를 거쳐 오는 구조라 2~3초 정도 걸려요. 웹·EXE·APK 모두 동일해요.
  • 교사 화면이 안 열려요 — 주소 끝에 ?role=teacher가 정확히 붙어 있는지 확인하세요. 파라미터 없이 접속하면 학생용 화면이 열려요.
  • 소리가 안 나요 — 웹은 시작 화면에서 시작하기를 눌렀는지(브라우저 정책상 첫 클릭이 필요해요), EXE·APK는 🔊 버튼에서 볼륨과 호출음을 확인하고 소리 테스트를 눌러보세요.
  • 급식·시간표가 안 나와요 — 설정 시트의 학교명이 정확한지, 유콜 ▸ 학교코드 조회를 실행했는지 확인하세요. 방학·주말에는 원래 표시되지 않아요.
  • 상주형 APK인데 호출 화면이 안 떠요 — 「다른 앱 위에 표시」 권한이 꺼져 있을 수 있어요. 설정 ▸ 애플리케이션 ▸ 유콜 보드 ▸ 권한에서 켜주세요.
  • EXE 설치할 때 파란 경고 화면이 떠요 — 윈도우 SmartScreen이에요. 추가 정보 ▸ 실행을 누르면 진행됩니다. 스토어를 거치지 않은 프로그램이면 다 뜨는 정상적인 경고예요.
  • EXE를 완전히 끄고 싶어요 — 트레이 아이콘(작업표시줄 오른쪽 하단)을 우클릭 ▸ 종료를 누르세요. X 버튼만 누르면 트레이로 숨을 뿐 계속 실행 중이에요.
  • 학생을 추가/삭제했는데 반영이 안 돼요 — 시트 저장 후 화면에서 새로고침(F5)하면 즉시 반영돼요. 재배포는 필요 없어요.
  • 교실마다 다르게 써도 되나요? — 됩니다. 1반은 웹, 2반은 EXE, 3반은 APK로 써도 서로 아무 영향 없어요.

🗑️삭제 방법

APK — 앱 아이콘을 길게 눌러 [제거]로 끌어다 놓거나, 설정 ▸ 애플리케이션 ▸ 유콜 보드 ▸ [제거]를 누르세요.

EXE — 트레이 아이콘 우클릭 ▸ 종료로 먼저 끈 뒤, 윈도우 설정 ▸ 앱 ▸ 유콜 데스크 ▸ 제거(또는 제어판 ▸ 프로그램 제거)를 누르세요.
