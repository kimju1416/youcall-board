# 유콜 보드 (Android)

📣 [유콜(YOUcall)](https://github.com/kimju1416/youcall-desktop) 전자칠판용 안드로이드 앱입니다.
안드로이드가 내장된 전자칠판(예: 컴버스테크 ND86PT 등)에 설치해서 씁니다.

> 💡 전자칠판에 **Windows PC를 연결해서** 쓰신다면 이 앱 대신
> [유콜 데스크(Windows용 exe)](https://github.com/kimju1416/youcall-desktop/releases/latest)를 설치하세요.

## 다운로드

[Releases](https://github.com/kimju1416/youcall-board/releases/latest)에서 `YouCallBoard.apk`를 받으세요.

## 설치 방법

1. APK 파일을 USB에 담아 전자칠판에 꽂습니다
2. 전자칠판의 **File Manager** 앱을 열어 APK 파일을 누릅니다
3. "출처를 알 수 없는 앱" 허용 안내가 나오면 허용합니다
4. 설치 후 앱을 실행하고, 우리 학교 유콜 웹앱 주소와 학년·반을 입력합니다

## 두 가지 동작 방식 중 선택

설정 화면에서 고를 수 있고, 나중에 ⚙️ 버튼으로 언제든 바꿀 수 있습니다.

| | 상시 화면형 (기본) | 상주형 (트레이) |
|---|---|---|
| 평소 화면 | 시간표·급식·학사일정·공지를 항상 표시 | 숨어 있음 (전자칠판을 다른 용도로 사용) |
| 호출이 오면 | 알림 화면으로 전환 | 앱이 자동으로 화면 앞으로 등장 |
| 호출이 끝나면 | 대기화면으로 복귀 | 다시 숨음 |

**상주형을 쓰실 때**는 첫 실행 시 안내되는 **'다른 앱 위에 표시'** 권한을 허용해야 합니다.
이 권한이 없으면 앱이 스스로 화면에 뜨지 못하고 상단 알림만 표시됩니다.

## 기능

- 교무실에서 호출하면 학생 이름·번호·메시지·선생님·오시는 곳을 크게 표시
- 호출음 8종 + 음성 안내(TTS), 볼륨·반복 횟수 조절
- 평소엔 오늘/이번주 시간표, 급식(칼로리·알레르기), 학사일정 D-day, 긴급공지, 학급메모 표시
- 화면 꺼짐 방지, 전자칠판 재부팅 시 자동 실행

## 개발

```
npm install
npx cap sync android
cd android && ./gradlew assembleRelease
```

빌드하려면 프로젝트 루트에 `youcall-release.keystore`가 필요합니다(저장소에 포함되지 않음).
